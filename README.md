# SAHA

A wrist-worn awareness prototype for body-focused repetitive behaviors (BFRBs), such as hair pulling, skin picking and nail biting.

SAHA is an awareness tool, not a medical device or treatment.

## Data

This project uses the Child Mind Institute "Detect Behavior with Sensor Data" dataset from Kaggle. The data is not stored in this repository. Download it from Kaggle and place it in `data/`.
